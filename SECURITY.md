# Security Policy

Security Health Check is maintained by v98881. Security reports are welcome.

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

- Use GitHub's private vulnerability reporting: open this repository → **Security** → **Report a vulnerability**.
- Describe the affected version, platform and the steps to reproduce.
- Do not include personal data, credentials, vehicle identification numbers or other sensitive information in the report.

Reports are acknowledged as soon as possible. There is no guaranteed response or fix time.

## Scope

In scope: vulnerabilities in the application itself, such as unsafe handling of files or data, unintended network connections, insecure storage of data on the device, or weaknesses in the published packages.

Out of scope: issues in third-party components that are already fixed upstream (please mention them anyway), findings on systems you are not authorised to test, and social-engineering attacks.
